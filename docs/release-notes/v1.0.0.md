UI4ME Core 1.0.0 is the stable Core: a native HTML/CSS desktop UI runtime for Python,
PowerShell and LuaJIT applications, on Linux x86-64 (Wayland/X11) and Windows x64.

**Stability.** ABI 1 and the wire schema are frozen under
[COMPATIBILITY.md](https://github.com/ui4me/ui4me/blob/main/docs/COMPATIBILITY.md). The
supported surface is the generated
[SUPPORT_PROFILE_V1.json](https://github.com/ui4me/ui4me/blob/main/docs/SUPPORT_PROFILE_V1.json):
CSS rows, wire ops with their binding coverage, events, and per-platform capabilities as
measured on KDE (Wayland) and Windows.

**New since 0.9**

- **Paged media and printing:**
  - `paginate`, `get_page_rects`, `render_page` and `export_pdf`.
  - `print_document` uses the native print dialog: the system dialog on Windows and the
    desktop's print portal on Linux.
- **Rich `contenteditable`:**
  - Formatting, paragraphs, sanitized paste and undo.
  - `exec_edit` and `get_edit_state`.
- **Background work:** `run_in_background` / `RunInBackground` settle on the owner thread.
- **Diagnostics:** `get_diagnostics` (schema 1, redacted by default) and `explain`.
- **Scale and robustness:** long-document scalability and a soak driver.
- **LuaJIT binding:** `ui4me-lua-1.0.0.zip`, a pure FFI binding over the C ABI.
- **Screen readers:** checked with NVDA (Windows) and Orca (KDE) journeys. Number inputs now
  expose their text to AT-SPI.
- **Release engineering:**
  - An upgrade/rollback matrix from 0.4.0; v0.4 clients pass on 1.0.
  - `SHA256SUMS` in the release assets.

**Deferred:** the GPU backend, macOS and ARM64.

Assets: the Python wheels (also on PyPI as `ui4me==1.0.0`), the PowerShell module (also on the
PowerShell Gallery as `Ui4me 1.0.0`), the native SDKs for linux-x64 and win-x64, the LuaJIT
binding, `manifest.json` and `SHA256SUMS`.

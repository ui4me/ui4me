UI4ME Core 1.0.1 is a maintenance release of the stable 1.0 Core. It adds no features. ABI 1,
the wire schema, the support profile and the Python and PowerShell APIs are unchanged and
compatible with 1.0.0.

**Fixes**

- **Python shutdown:** `App.close()` (also at the end of `with App() as app:`) no longer hangs
  on a background function that ignores cancellation. It waits up to 30 s
  (`close(timeout=...)`, `None` for the old unlimited wait), then leaves that function on its
  worker thread with a `RuntimeWarning`. No thread is killed.
- **LuaJIT:** now on LuaRocks (`luarocks install ui4me`). The `ui4me-lua-1.0.1.zip` asset
  contains a README, the licence and the notes example. The binding does not include the native
  library: use `lib/` from the native SDK zip of the same version (`UI4ME_NATIVE_LIB`, or place
  it next to `ui4me.lua`).
- **Trustworthy gates:** the native release gates on Linux and Windows end with a single
  verdict. A missing, skipped or failed mandatory step now fails the gate (in 1.0.0 a failed
  Windows LuaJIT step went unnoticed). Gate preparation deletes only directories it created.
- **Real binding checks:** Python and PowerShell tests call every declared wire operation
  through the public API, replacing a source-text search.
- **Honest soak and memory checks:** unmeasured metrics or too few samples fail; Windows memory
  is measured on the application process.
- **Publishing:** the release workflow runs the unit tests and installs and smoke-tests the
  exact packages on Linux and Windows before anything is published.

**Qualification** (candidate `5b9f9fd`): unit and installed-package suites passed on Linux and
Windows; the native desktop gate passed on KWin (19/19 steps) and on Windows Server 2022 (18/18,
including NVDA, the LuaJIT unit tests and the upgrade matrix from 0.4.0). A one-hour Linux soak (55 sessions, flat memory, no errors) and a 10-minute Windows soak passed. All input
in these tests is automated.
